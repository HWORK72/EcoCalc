Аналитический вычислительный движок для прогнозирования траектории государственного долга и оценки устойчивости экономики на основе макроэкономических дифференциалов роста.

### Архитектурные особенности:
* **Формульное макроэкономическое моделирование:** Расчет динамики отношения долга к ВВП (Debt-to-GDP ratio) на основе разницы между темпами роста реального ВВП и стоимости обслуживания долга.
* **Детерминированный прогноз платежеспособности:** Определение фискального тренда: если показатель снижается (отрицательная дельта), экономика находится в фазе устойчивого роста, и наоборот.
* **Параметрический ввод:** Поддержка симуляции как сценариев реальных суверенных экономик, так и замкнутых игровых экономических систем.
* **Модульная математическая база:** Изолированная вычислительная логика, готовая к интеграции в дашборды или API-эндпоинты.

### Стек технологий:
* Python 3.12
* Математическое моделирование и расчет дифференциалов
* Чистый Python без внешних зависимостей
