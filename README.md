# EcoCalc
Калькулятор экономики страны
Изначально создавался как удобный калькулятор для игры, но спокойно можно вписать сюда данные реальной страны и он выдаст изменение доли долга к ввп страны по формульному способу экономистов.
Любая страна в плюсе, если экономика растет быстрее чем долги. Этот калькулятор считает по вводным данным прогноз отношения долга к ВВП. Если это отношение падает (с минусом), то экономика растет, и наоборот
